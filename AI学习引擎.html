AI 学习引擎

输入一个领域，自动生成分阶段学习计划 + 该领域的具体内容（20% 核心概念、学习顺序、资源、类比、多视角大纲、费曼检验、可动手项目）。数据仅存于本机浏览器。

第一次用？3 步：① 上方选 DeepSeek（已默认）；② 打开 platform.deepseek.com 注册→实名→API Keys 创建密钥→支付宝/微信充值；③ 把 Key 粘到下方，回到主页点「生成」。不想填 Key 可先点「载入示例」体验。想把网页分享给别人或在手机上免配置用，可部署 relay-server.js 后勾选下方「带 Key 的中转」。 

      

        傻瓜式启动：直接双击工作目录里的 启动代理.bat（Windows）即可，保持窗口开着。密钥只经你本机转发，不经第三方。需要 Node.js（已自带则无需安装）。
      

    


    

      
      

        

      
      
    

    

      把 API Key 放在你自己的服务器（relay-server.js）上，网页只把「提示词」发给中转，Key 永不出现在浏览器里。最适合把网页分享给朋友、或在手机上免配置使用。本地调试可把 relay 跑在 http://localhost:8788。注意中转地址需允许跨域（已内置 CORS）。
